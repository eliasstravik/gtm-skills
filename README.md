## Frequently asked questions

### Do I need to know how to code?

No code is required to run the guided skills. You need `npx`, an AI agent that loads installed skills, and Git for the GTM context repository.

### What gets installed?

The main install command adds all nine GTM skills. Run `/gtm-context` first, then invoke segmentation, scoring, or research as needed.

### What does GTM Context store?

It stores your organization’s durable self-knowledge: organization facts, teammates, suborganizations, ICPs, and personas. Account and lead research stays in the response instead of becoming repository state.

### Can different teams keep different ICPs and personas?

Yes. The root organization and its suborganizations can own their own definitions. Downstream skills inspect only the artifacts visible to the selected organization node.

### Can research browse the web or write to our CRM?

Research skills can inspect safe web sources when browsing is available. Their output is response-only: they do not write to files, Git, a CRM, or another system.

### What does it cost?

GTM Skills is free, open source, and MIT licensed. Your AI or model provider may charge for usage.
