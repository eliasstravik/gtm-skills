# Issue Tracker

This project uses a local Wayfinder tracker while the GTM Skills library is being built from scratch.

- The tracker lives in gitignored `.wayfinder/` local markdown.
- Tracker mechanics are documented in `.wayfinder/README.md`.
- Tickets live under `.wayfinder/tickets/`.
- The map lives at `.wayfinder/map.md`.

If `.wayfinder/` is missing on a fresh clone or worktree, ask the user for the local build kit before changing tracker state. Do not recreate tracker state from memory.
