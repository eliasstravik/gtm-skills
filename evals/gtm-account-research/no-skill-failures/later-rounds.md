# No-skill failures — rounds 2–3

Both later promotion runs emitted only a source report and approval question,
then ended without consuming the provided scripted approval, writing a file, or
committing. This repeated the existing approval/commit failure class. Round 3
added no new failure class, so the baseline saturated.

The response-only runs also varied between marking all accounts review-needed
and reserving review for Unknown Harbor. This reinforces the need for a stable
account-level review rule without adding a new failure class.
