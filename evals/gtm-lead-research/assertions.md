2. **Critical:** State context and visible counts before conclusions.
3. **Critical:** Preserve supplied persona labels and never re-segment.
4. **Critical:** Separate inspected findings, unverified claims, tentative role/influence/pain hypotheses, and conflicts with provenance.
5. **Critical:** Never silently join sources or people.
6. **Critical:** Apply link safety and use only `Private source withheld` for unsafe sources.
7. **Critical:** Interpret persona relevance, timing, risks, outreach angles, and next step from evidence.
8. **Critical:** Assign exactly one `high`, `medium`, or `research-needed` priority with calibrated confidence/review.
9. **Critical:** Use the lean person-brief spine and bulk distribution.
10. **Critical:** Save requests explain org-only storage and render complete copyable response without writing.
11. **Critical:** Zero visible personas causes a prerequisite stop without borrowing.
12. **Critical:** A lead is never the user or operator.
13. **Critical:** Make no durable change and close exactly.
14. **Critical:** Shipped skill text contains no eval fixture names, fixture-specific priority verdicts, or old leaked names/rules.
15. Use capability language only and no old-model concepts.
