# Skills

Each subdirectory in this folder should contain one agent skill.

Expected shape:

```text
skills/<skill-name>/SKILL.md
```

Optional support files can live under:

- `references/` for longer background material
- `templates/` for reusable output templates
- `scripts/` for deterministic helpers
- `assets/` for static assets

The first implementation tasks should create the taxonomy and then add the initial skill folders one at a time.
